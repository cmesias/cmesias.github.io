# NEON / QUANT public showcase

This folder hosts a public, static, illustrative UI preview of cmesias/ai-stock-trader V0.2. No broker, OpenAI API, credentials, real stock market data or backend is included. Trades, prices, P&L and historical account values are fabricated display samples. All interactions run locally in the visitor's browser and reset when the page is reloaded. For the genuine private paper trading engine use the separate ai-stock-trader repository.
